SHRIMP Button Consolidation — Demo

Hover over each button to see the proposed hover state. Use the theme switcher to verify all themes.

1. btn-primary — pill action buttons

Matches the scope pill style from the chat page: pill shape, accent border, accent text, transparent background. Active state fills with accent-dim. Responds to theme changes.

scope-pill — existing toggle pills (no change)

Already used in the chat header and project settings. Shown here as a reference point for how toggle/pill patterns should feel. btn-secondary.active is designed to match this aesthetic for non-pill contexts.

2. btn-secondary — small labeled action buttons

Transparent bg + muted border at rest. Accent tint + accent text on hover. Use for: Reply, Forward, Run Now, Enable/Disable, Archive. Danger variant for destructive actions. Active variant for toggle groups.

3. icon-btn — prominent icon actions (accent emphasis)

Accent border + accent-dim background. Reserved for important header actions only: Compose, Fetch emails. Already mostly correct; no major change.

4. btn-ghost — borderless utility icon buttons

No visual presence at rest (muted color, transparent bg). Subtle white tint on hover. Use for: Back arrow, Refresh (JobsPanel header), Copy, inline flag/star actions. Replaces all the custom p-1.5 rounded hover:bg-shrimp-border/50 patterns.

5. btn-card — dashboard QuickAction cards

Surface background + border. Lifts slightly and gets accent tint on hover. Replaces the raw Tailwind hover:bg-shrimp-border/40 pattern on QuickAction cards which was inconsistent with the rest of the app.

6. nav-btn — navigation rail

No change from current. Shown for completeness.
